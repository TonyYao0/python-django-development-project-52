## Описание
«Менеджер задач» — это полноценное веб-приложение для управления проектами и задачами, разработанное в рамках обучения на платформе Hexlet. Сервис позволяет регистрировать пользователей, создавать гибкие статусы жизненного цикла, привязывать метки к задачам и фильтровать списки по нескольким критериям.

### Основные возможности:
* **Аутентификация и CRUD Пользователей:** Безопасная регистрация, вход/выход, защита профилей от редактирования посторонними лицами.
* **Статусы задач:** Настройка кастомных этапов выполнения (например: *Новая*, *В работе*, *Завершена*).
* **Метки (Labels):** Тегирование задач для удобной классификации с использованием связи Many-to-Many.
* **Задачи:** Назначение исполнителей, автоматическое определение автора, жесткие ограничения прав (удалять задачу может только её создатель).
* **Продвинутая фильтрация:** Поиск задач по исполнителю, статусу, меткам, а также быстрый фильтр «Только свои задачи».
* **Целостность данных (Safety):** Блокировка удаления пользователей, статусов и меток, если они привязаны к активным задачам (`models.PROTECT`).
* **Мониторинг ошибок:** Полная интеграция с платформой **Rollbar** для отслеживания багов в продакшене.

## Стек технологий
* **Язык:** Python 3.12+
* **Фреймворк:** Django 6.0 (Class-based Views)
* **Интерфейс:** Bootstrap 5 (через django-bootstrap5)
* **Фильтрация:** Django Filter
* **Базы данных:** SQLite (локально) / PostgreSQL (в продакшене через dj-database_url)
* **Статика:** WhiteNoise (сжатие и кэширование)
* **Пакетный менеджер:** uv

## Установка и запуск

### 1. Требования
Убедитесь, что на вашем компьютере установлен Python версии 3.10+ и менеджер пакетов `uv`.

### 2. Клонирование репозитория
```bash
git clone github.com
cd python-django-development-project-52
```

### 3. Настройка окружения и зависимостей
```bash
# Синхронизация окружения и установка пакетов
uv sync
```

### 4. Конфигурация секретов (`.env`)
Создайте локальный файл `.env` в корне проекта для хранения секретов (он автоматически игнорируется Git):
```ini
DEBUG=True
SECRET_KEY=your-local-safe-secret-key
DATABASE_URL=sqlite:///db.sqlite3
ROLLBAR_ACCESS_TOKEN=your_rollbar_token
```

### 5. Миграции и сборка статики
```bash
uv run python manage.py migrate
uv run python manage.py collectstatic --no-input
```

### 6. Запуск сервера
```bash
uv run python manage.py runserver
```
Приложение станет доступно по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
